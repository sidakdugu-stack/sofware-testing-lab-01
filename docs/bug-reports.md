# Отчёты о дефектах

## Дефект 1. Совершеннолетний пользователь получает отказ в регистрации

- **Серьёзность:** Высокая
- **Приоритет:** Высокий
- **Окружение:** Тестовая версия, Chrome 120, Windows 11
- **Предусловия:** Открыта форма регистрации

**Шаги:**
1. Ввести имя `Тест`.
2. Ввести email `test@mail.ru`.
3. Ввести пароль `Passw0rd`.
4. Ввести дату рождения так, чтобы сегодня исполнилось ровно 18 лет.
5. Нажать «Зарегистрироваться».

**Фактический результат:** Показано сообщение «Регистрация доступна только с 18 лет».
**Ожидаемый результат:** Регистрация успешна, пользователь видит сообщение об успехе.
*(Ожидаемый результат — предположение: граница 18 лет трактуется как «уже можно».)*

## Дефект 2. Двойное нажатие кнопки создаёт две учётные записи

- **Серьёзность:** Высокая
- **Приоритет:** Высокий
- **Окружение:** Тестовая версия, Chrome 120, Windows 11
- **Предусловия:** Открыта форма регистрации, email `dup@mail.ru` не занят

**Шаги:**
1. Заполнить все поля корректными данными.
2. Быстро дважды нажать кнопку «Зарегистрироваться».

**Фактический результат:** Создаются две учётные записи с одинаковым email.
**Ожидаемый результат:** Создаётся ровно одна учётная запись; кнопка блокируется после первого нажатия.
*(Ожидаемый результат — предположение: email должен быть уникальным по требованию 3.)*

## Дефект 3. Техническое сообщение об ошибке раскрывает объект пользователя

- **Серьёзность:** Высокая
- **Приоритет:** Высокий
- **Окружение:** Тестовая версия, Chrome 120, Windows 11
- **Предусловия:** Email `exists@mail.ru` уже зарегистрирован

**Шаги:**
1. Заполнить форму, указав email `exists@mail.ru`.
2. Нажать «Зарегистрироваться».

**Фактический результат:** В сообщении об ошибке отображается полный объект пользователя (включая внутренние поля и данные).
**Ожидаемый результат:** Показывается нейтральное понятное сообщение без технических данных и объектов.
*(Ожидаемый результат — предположение: требование 6 «понятное сообщение».)*
